# ClimbStat

## API
Nest.js

## Objectif
Application inspiré de Arkose+ permettant d'afficher ses statistiques et peformances d'escalade

## Fonctionnalités
- Chercher sa salle d'escalade
- Noter les blocs topés / flashés
- Dashboard avec les statistiques de l'utilisateur
